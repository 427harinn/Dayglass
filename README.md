# Dayglass

作業セッションの残り時間と予定の流れを「砂時計」で表現するスケジュールタイマーです。

作業中に予定表を読み続けなくても、残り時間・現在の流れ・次に意識するポイント（next point）が分かることを目指しています。

## 画面構成

- **Setup**：セッションとイベントの編集
- **Focus**：砂時計を中心にした最小表示
- **Focus Details**：必要なときだけ開く詳細

## 技術構成

- React 19 + TypeScript + Vite 7
- データ保存は localStorage（破損時はデフォルトセッションへフォールバック）
- バックエンド・カレンダー連携なし
- PWA は manifest・theme-color・仮アイコンの土台まで準備済み
